========================================================================
學生就學貸款 PDF 檔案自動化處理、審查與留存規劃書 (最新完整版)
========================================================================

一、 系統架構總覽
1. 觸發端：Google 表單收到學生回覆後，觸發 Google Apps Script (GAS) onFormSubmitHandler。
2. 傳輸通道：GAS 透過設定好之「Tailscale Funnel」HTTPS 網域，將 PDF 檔案 (轉為 Base64) 與相關個資安全地傳送進內網 QNAP NAS (Port 55000)。
3. 接收與處理端：QNAP NAS 上的 Container Station 運行一個 Python Flask Docker 容器。
   - 容器會接收三種 PDF：臺銀對保單、已登錄確認單、可貸金額明細表。
   - 每種 PDF 都有專屬的驗證機制 (文字特徵 + 學年度學期日期驗證)。
   - 伺服器會使用密碼 (身分證號) 解開加密的「臺銀對保單」，並萃取文字與印章圖片後回傳給 GAS。
   - 系統依據當前有效的學年度及學期自動新增子目錄 (例如 115-1/)，並依據「學年度-學期-學號姓名-檔名」規則統一儲存。
4. 審查與寫入端：GAS 接收回傳資料後：
   - 執行七大核心審查規則 (基本資料比對、有效學期檢驗、申貸金額上限不可超貸、減免補貼金額一致性、確認單與對保單金額一致性)。
   - 分別寫入「臺銀對保單」、「登錄確認單」、「可貸金額明細表」三個原始資料分頁。
   - 將審查結果寫入「審查結果」專屬分頁 (學年度、學期、電子郵件地址、學制、班級、學號、姓名、身分證號、審查結果、審查時間)。
   - 刪除留存在 Google 雲端硬碟中的 PDF 暫存檔案 (移至垃圾桶)。
   - 自動將審查結果以 HTML E-Mail 發送通知學生。
5. 查詢端：學生可隨時在 GitHub Pages (自動 CI/CD 部署) 或嵌入之 Google Sites 網頁輸入學號即時查詢審查結果。

【部署步驟】
1. 開啟 QNAP，透過 SSH 進入您的專案資料夾 (例如 `cd /share/Container/pdf_parser/`)。
2. 確保上述 4 個檔案皆已存在該目錄中。
3. 執行指令啟動容器：
   docker compose down
   docker compose build --no-cache
   docker compose up -d
4. 若要查看運行狀態，使用 `docker compose ps` 或 `docker compose logs -f`。

三、 Tailscale Funnel 設定 (轉發外部請求至內部 Port 55000)
========================================================================
在 NAS 的 SSH 終端機執行：
1. 啟用背景服務轉發：
   /share/CACHEDEV1_DATA/.qpkg/Tailscale/tailscale serve https / http://127.0.0.1:55000
2. 啟用對外開放漏斗：
   /share/CACHEDEV1_DATA/.qpkg/Tailscale/tailscale funnel on
3. 檢查轉發狀態並複製 Public HTTPS 網址：
   /share/CACHEDEV1_DATA/.qpkg/Tailscale/tailscale serve status
